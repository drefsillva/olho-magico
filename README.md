## &#x20;Sobre o projeto

**Olho Mágico** é um projeto de animação visual desenvolvido em Python que combina a representação de um olho com uma transição para um cenário espacial, repleto de estrelas, efeitos luminosos e um coração cósmico.

Este projeto faz parte da minha jornada de aprendizado em Engenharia de Software e representa uma oportunidade de explorar código, lógica de programação e personalização visual.

## &#x20;Personalizações

Nesta versão, fiz alterações para dar ao projeto uma identidade visual própria:

- &#x20;**Íris verde:** tonalidade verde com detalhes castanhos próximos à pupila.
- &#x20;**Coração roxo:** combinação de roxo escuro e lilás.
- &#x20;**Efeitos luminosos:** preservação dos efeitos visuais da animação.
- &#x20;**Título personalizado:** a janela agora se chama *Olho Mágico*.

## &#x20;Como executar

### 1. Pré-requisitos

- Python instalado no computador.
- Git, caso queira clonar o repositório.
- Biblioteca NumPy instalada.

### 2. Clonar o repositório

```bash
git clone https://github.com/drefsillva/olho-magico.git
```

### 3. Entrar na pasta

```bash
cd olho-magico
```

### 4. Instalar a dependência

```bash
python -m pip install numpy
```

### 5. Executar o projeto

```bash
python olhomagico.py
```

> **Observação:** o comando de execução pressupõe que o arquivo principal se chama `olhomagico.py`. Se o nome do arquivo estiver diferente na pasta, ajuste o comando para usar o nome correto.
